# Intelligence Engine V1.8 Release

## Investigation Canvas UI

V1.8 adds the first interactive frontend milestone for the V1.7 Investigation Workflow Engine.

### Included
- n8n-style draggable workflow canvas
- typed analysis-node palette
- input/output pins and edge creation
- workflow reset/delete interactions
- selected-node configuration inspector
- deterministic local preview trace
- dark tactical investigation visual system aligned with the existing Clarity frontend

### Deliberate boundary
This release does not claim live execution against an evidence graph. Backend workflow execution integration is a later milestone.
