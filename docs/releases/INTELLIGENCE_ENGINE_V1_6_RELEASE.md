# Intelligence Engine V1.6 Release

## Milestone
Suspicious Pattern / Anomaly Engine

## Added
- Explainable activity-spike detection
- Novel relationship detection
- Pair interaction burst detection
- Baseline-community cross-boundary interaction detection
- Structural-role + activity convergence leads
- Deterministic baseline generation
- Evidence/event/relationship provenance on findings
- Explicit invalid/undated-time handling
- Stable finding IDs and ordering
- Dedicated unit tests and verification documentation

## Safety boundary
The engine identifies unusual patterns and investigative leads. It does not determine guilt, criminality, or enforcement action.
